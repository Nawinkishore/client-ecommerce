# Web Application (`@client-ecommerce/web`)

Next.js frontend application configured with TypeScript, Tailwind CSS, TanStack Query, Axios, and Zod.

## Workspace Purpose
Handles client user interfaces, page rendering, layout components, and frontend state management.

## Scripts
- `pnpm dev`: Start Next.js development server
- `pnpm build`: Build production web bundle
- `pnpm type-check`: Run TypeScript compiler validation
