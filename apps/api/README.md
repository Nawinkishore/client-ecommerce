# Backend API Server (`@client-ecommerce/api`)

Node.js + Express backend application configured with TypeScript and Prisma ORM.

## Workspace Purpose
Handles HTTP routing, business controllers, middleware, data persistence, and database interactions.

## Scripts
- `pnpm dev`: Run local development server using `tsx` watcher
- `pnpm build`: Compile TypeScript into JavaScript `dist/`
- `pnpm type-check`: Validate types across backend files
- `pnpm prisma:generate`: Generate Prisma Client
